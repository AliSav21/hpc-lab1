# Інструкція запуску

Потрібен лише Docker (Docker Desktop або Docker Engine з плагіном Compose).

## 1. Разове налаштування секрету

```bash
cp .env.example .env
```

Відкрити `.env` і замінити `change-me` на будь-який пароль. Пароль не можна тримати в
`docker-compose.yml`, тому цей крок виконується окремо від підняття стенду.

## 2. Одна команда піднімає стенд

```bash
docker compose up -d --build
```

Команда збирає образ і піднімає три сервіси: базу, вебінстанс і балансувальник.
Схема таблиці накочується автоматично. Сервіс доступний через балансувальник:

```bash
curl http://127.0.0.1:18080/healthz
```

Відповідь `{"status":"ok"}` означає, що стенд готовий.

Інтерактивна документація з усіма ендпоінтами відкривається в браузері:

```
http://127.0.0.1:18080/docs
```

Запити звідти можна надсилати кнопкою Try it out. Від запуску до першої відповіді
приблизно 12 секунд: база ініціалізується на порожньому томі, потім проходять healthcheck-и.

## Два вебінстанси

Кількість вебінстансів задається одним параметром, файли не правляться:

```bash
WEB_REPLICAS=2 docker compose up -d
```

У PowerShell цей синтаксис не працює, там те саме робить:

```bash
docker compose up -d --scale web=2
```

## Зупинка

```bash
docker compose down
```

Дані бази залишаються в томі `pgdata`. Щоб видалити й том:

```bash
docker compose down -v
```

## Перевірка роботи

```bash
python scripts/verify_flow.py
```

Проходить повний цикл: створення, перелік, читання за ідентифікатором, заміна, видалення
і повторне видалення. Журнал пишеться у `results/verify_log.md`.
